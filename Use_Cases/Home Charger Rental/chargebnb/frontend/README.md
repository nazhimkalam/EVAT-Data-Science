# ChargeBnB React Frontend

This directory contains the React-based frontend for ChargeBnB.

## Install and run

```bash
cd frontend
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal (typically `http://127.0.0.1:5173`).

The frontend calls the backend at `http://127.0.0.1:8000` by default.
