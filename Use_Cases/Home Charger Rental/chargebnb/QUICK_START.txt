🐛 TROUBLESHOOTING

Port 8001 already in use?
    macOS/Linux: lsof -i :8001 | grep LISTEN | awk '{print $2}' | xargs kill -9
    Windows: netstat -aon | find ":8001"

Port 5173 already in use?
    macOS/Linux: lsof -i :5173 | grep LISTEN | awk '{print $2}' | xargs kill -9
    Windows: netstat -aon | find ":5173"

Backend won't start?
    1. Check: python --version (should be 3.8+)
    2. Install: pip install -r backend/requirements.txt
    3. Check logs: tail -f /tmp/chargebnb_backend.log

Frontend won't start?
    1. Check: node --version (should be 14+)
    2. Check: npm --version
    3. Install: npm install (in frontend directory)
    4. Check logs: tail -f /tmp/chargebnb_frontend.log

💡 TIPS

• Hot Reload: Frontend changes are auto-reloaded. Just refresh your browser.
• Backend Changes: Require server restart. Stop and run ./start.sh again.
• API Documentation: Visit http://localhost:8001/docs for interactive API docs.
• Database: SQLite file (chargebnb.db) stored in backend directory.
• Development Mode: HMR enabled for fast development feedback.
